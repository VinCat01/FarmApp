## 🎯 Функциональные возможности

### Для всех пользователей
- 📊 **Дашборд** — главная панель с общей статистикой (поголовье, поля, склад)
- 📋 **Журнал работ** — просмотр и фильтрация записей

### Для работников (`worker`)
- 📝 **Добавление записей** в журнал работ (кормление, уборка, сбор и т.д.)
- 🌾 **Учёт продукции** — фиксация сбора урожая/продукции

### Для менеджеров (`manager`)
- ❤️ **Ветеринарные планы** — создание, просмотр, управление
- 🌱 **Севооборот** — планирование посадок на полях
- 🛒 **Закупки** — учёт приобретаемых товаров и материалов
- 💰 **Продажи** — оформление и отслеживание продаж продукции
- 📈 **Отчёт о прибыли** — детальная финансовая отчётность с рентабельностью

### Для администраторов (`admin`)
- 👥 **Управление пользователями** через панель администратора
- ⚙️ **Полный доступ** ко всем справочникам (животные, виды, поля, склад и т.д.)
- 📜 **Журнал действий** — аудит всех операций пользователей

## 🚀 Установка и запуск

### Требования
- Python 3.12+
- PostgreSQL (установленный и запущенный)
- Poetry (рекомендуется)

### 1. Клонирование репозитория
```bash
git clone <url-репозитория>
cd FarmApp
```

### 2. Установка зависимостей
```bash
poetry install
```

Или через pip:
```bash
pip install -r requirements.txt
```

### 3. Настройка базы данных
Убедитесь, что PostgreSQL запущен. Настройки подключения в `farmapp_project/settings.py`:
```python
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.postgresql",
        "NAME": "FarmApp",
        "USER": "postgres",
        "PASSWORD": "postgres",
        "HOST": "localhost",
        "PORT": "7777",
    }
}
```

### 4. Применение миграций
```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Запуск сервера
```bash
python manage.py runserver
```

Приложение будет доступно по адресу: **http://127.0.0.1:8000**

## 🌱 Наполнение базы данных

Проект включает 2 management-команды для заполнения БД тестовыми данными.

### Шаг 1: Создание ролей и пользователей
```bash
python manage.py seed_roles
```

Создаёт:
- 3 роли: Работник, Менеджер, Администратор
- 3 тестовых пользователя (см. раздел [Учётные данные](#-учётные-данные))

python manage.py seed_data

## 👥 Роли пользователей

- Управление пользователями
- Просмотр журнала действий
- Управление справочниками (животные, поля, склад и т.д.)

## 📊 Модели данных

| Модель | Описание | Ключевые поля |
|--------|----------|---------------|
| **Species** | Виды животных | name |
| **Animal** | Животные | inventory_number, species, birth_date, gender, status, responsible_person |
| **Field** | Сельхозполя | cadastral_number, area, status |
| **Storage** | Склад/Запасы | name, item_type, quantity, unit |
| **CropRotation** | Севооборот | field, crop, planting_date, harvest_planned |
| **VeterinaryLog** | Вет. журнал | animal, data, description, cost |
| **VetPlan** | Вет. планы | title, procedure_type, species, planned_date, assigned_to, status, estimated_cost |
| **WorkLog** | Журнал работ | user, action_type, target_type, target_id, description, quantity |
| **Purchase** | Закупки | item, quantity, price_per_unit, supplier, invoice_number |
| **SaleOrder** | Продажи | item, quantity, price_per_unit, buyer, status |
| **ActionLog** | Журнал действий | user, action, model_name, object_id, description, timestamp |
| **CustomUser** | Пользователи | username, full_name, phone, position, role |
| **Role** | Роли | name, codename, description |

## 🐛 Известные особенности

1. **Фильтр по дате для вет. расходов** — в отчёте о прибыли учитываются вет. планы со статусом "completed" за выбранный период
2. **Рентабельность** — рассчитывается как `(прибыль / расходы) * 100%`
3. **Аккордеон в сайдбаре** — разделы "Рабочие операции" и "Управление" свёрнуты для компактности
